# TOHOKU STAY CARE — 営業支援システム Phase 1

東北6県の民泊・宿泊施設に「交換・リフォームする前に、補修という選択肢」を提案するための、ブラウザ完結型の営業候補管理ツールです。

## この構成を選んだ理由

- **HTML / CSS / JavaScriptだけ**：サーバー契約やデータベース、APIキーが不要で無料運用できます。
- **古いMacでもブラウザで操作**：Chrome / Safari / Firefoxの比較的新しい版に対応します。
- **データは端末内**：入力内容はブラウザの `localStorage` に保存され、外部へ自動送信されません。
- **人が最終確認**：営業文は下書きの生成とコピーだけ。自動送信・大量送信は行いません。

> 注意：ブラウザの履歴・サイトデータを削除すると登録内容も消えます。定期的にCSVを出力してバックアップしてください。同じURLでも別のブラウザや別のPCにはデータは共有されません。

## まず使う（初心者向け）

### GitHub Pagesで公開する場合（おすすめ・無料）

1. GitHubでこのリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の Source を **Deploy from a branch** にします。
3. Branchで利用するブランチと `/(root)` を選び **Save** します。
4. 数分後に表示されるURLをMacのブラウザで開き、ブックマークします。

公開URLを知っている人が画面自体を開ける構成です（データは各ブラウザ内）。機密情報を扱う、複数人で共有する場合はPhase 2で認証とデータベースを追加してください。

### 手元で確認する場合

Python 3がある端末で次を実行し、`http://localhost:4173` を開きます。

```bash
npm start
```

依存パッケージのインストールは不要です。`index.html` の直接表示ではなく、上記のローカルサーバーを使ってください。

## 操作方法

1. **新規施設を登録**から情報を入力します。不明な項目は「不明」のままで構いません。
2. 保存すると条件に応じて優先度 S / A / B / C と判定理由が自動表示されます。
3. 検索欄と3種類の絞り込みで候補を整理し、一覧上で営業ステータスを更新します。
4. **営業文テンプレート**で施設・補修箇所を選び、文面を編集してコピーします。必ず人が確認してから、普段使うメール等で送信します。
5. **CSV出力**を定期的に行い、安全な場所へ保管します。Excelでも文字化けしにくいUTF-8 BOM付きです。

サンプル6件は初回アクセス時だけ自動登録されます。URLは架空の `example.com` で、実在施設の情報ではありません。

## 優先度ルール

ペット可・一棟貸し・木質床・複数施設運営は各2点、宿泊施設種別と連絡先確認済みは各1点です。

- **S（7点以上かつ該当理由4件以上）**：複数の強い条件が揃う
- **A（4点以上）**：宿泊施設または複数施設運営で営業価値が高い
- **B（2点以上）**：一般的な宿泊施設
- **C**：情報不足、または優先度が低い

ルールは `js/priority.js` に分離しており、今後の実績を見ながら安全に調整できます。

## 安全な運用ルール

- 施設情報は公式サイト等を**人が確認して登録**してください。利用規約と `robots.txt` を守り、無断スクレイピング、CAPTCHA回避、アクセス制限突破はしないでください。
- 公開情報であっても目的に必要な情報だけを扱い、CSVの共有範囲に注意してください。
- 営業文は事実確認・宛先確認・配信停止希望への対応を行い、一斉自動送信しないでください。
- APIキーやパスワードを追加する場合はコードに書かず、将来のホスティングサービスの環境変数を使います。

## テスト

```bash
npm test
```

Node.js標準テストランナーだけを使うため、`npm install` は不要です。

## ファイル構成

```text
index.html             画面構造
styles.css             デザイン・スマートフォン対応
js/app.js              登録、検索、保存、CSV、営業文機能
js/priority.js         優先度判定（単体テスト可能）
data/samples.js        東北6県の架空サンプル
tests/priority.test.js 優先度の自動テスト
```

## Phase 2の候補

Supabase等の無料枠を用いたログイン・複数端末同期、担当者と次回連絡日の管理、写真付き補修相談、監査ログを検討します。導入時はプライバシーポリシー、アクセス権、バックアップ方針も先に決めます。
